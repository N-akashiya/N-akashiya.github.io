A simple graph is bipartite iff it is possible to assign one of two different colors to each vertex of the graph so that no two adjacent vertices are assigned the same color.

PROOF:

→

\(V = V_1 \cup V_2\), \(V_1 \cap V_2=\emptyset \), and each edge in \(E\) connects a vertex in \(V_1\) and a vertex in \(V_2\). If we assign a first color to each vertex in \(V_1\) and a second color to each vertex in \(V_2\), no two adjacent vertices will have the same color.

←

Let \(V_1\) be the set of vertices assigned the first color, and \(V_2\) be the set of vertices assigned the second color. In this case, \(V_1 \cap V_2=\emptyset \) and \(V = V_1 \cup V_2\).

Since adjacent vertices never belong to the same set, each edge connects a vertex in \(V_1\) and a vertex in \(V_2\). Therefore, \(G\) is a bipartite graph.

PROOF:

→

Suppose that \(G\) has a complete matching \(M\). For every \(A\subseteq V_1\), the vertices of \(A\) are matched to \(|A|\) distinct vertices in \(N(A)\). Hence, \(|N(A)| \ge |A|\).

←

  1. Base case: \(|V_1| = 1\)

  2. Inductive step
    Assume that a complete matching exists when \(|V_1| \le k\), and consider a graph with \(|V_1| = k+1\)

    1. Every nonempty proper subset has strict inequality
      For any proper subset \(A\) (\(1\le |A| \le k\)), we have \(|N(A)| \ge |A| + 1\)

      • Choose any \(v \in V_1\) and one of its neighbors \(w \in V_2\). Delete \(v\) and \(w\), and let the resulting graph be \(G'\).

      • For every \(A \subseteq V_1 \setminus \{v\}\),
        \(|N_{G'}(A)| \ge |N(A)| - 1 \ge |A|\)

      • \(G'\) also satisfies Hall’s condition. By the induction hypothesis, \(G'\) has a complete matching. Adding the edge \(vw\) gives a complete matching in \(G\).

    2. Some nonempty proper subset has equality
      There exists a nonempty proper subset \(A \subsetneq V_1\) satisfying \(|N(A)| = |A|\). Let \(B = N(A)\).

      • The subgraph \(G_1 = G[A \cup B]\) clearly satisfies Hall’s condition. By the induction hypothesis, \(G_1\) has a complete matching \(M_1\).

      • The remaining graph \(G_2 = G[(V_1\setminus A)\cup (V_2\setminus B)]\)
        反证法：Assume that some \(X\subseteq V_1\setminus A\) satisfies \(|N_{G_2}(X)| < |X|\)

        • Since \(B = N(A)\),
          \(|N(X \cup A)| = |N_{G_2}(X)| + |B|\)

        • and \(|B| = |A|\),
          \(|N_{G_2}(X)| + |B| < |X|+|A|\)
          \(|N(X \cup A)| < |X \cup A|\)
          contradicting Hall’s condition in \(G\). So \(G_2\) satisfies Hall’s condition. By the induction hypothesis, \(G_2\) has a complete matching \(M_2\).

      • Since \(G_1\) and \(G_2\) have disjoint vertex sets, \(M_1\cup M_2\) is a complete matching from \(V_1\) to \(V_2\) in \(G\).

Graph Isomorphism

The simple graphs \(G_1=(V_1,E_1)\) and \(G_2=(V_2,E_2)\) are isomorphic if there exists a one-to-one and onto function \(f\) from \(V_1\) to \(V_2\) with the property that \(a\) and \(b\) are adjacent in \(G_1\)if and only if \(f(a)\) and \(f(b)\) are adjacent in \(G_2\), for all \(a\) and \(b\) in \(V_1\).

\(f\): an isomorphism

There is a simple path between every pair of distinct vertices of a connected undirected graph.

PROOF:

Let \(u\) and \(v\) be two distinct vertices in \(G\). Since \(G\) is connected, there exists at least one path between \(u\) and \(v\).

Choose the shortest path among these paths, and let its vertex sequence be \(x_0, x_1, \dots, x_n\) (\(x_0=u\) and \(x_n=v\)).

Suppose that this path is not simple. Then there exists a section where \(x_i=x_j\) for some \(i\) and \(j\) (\(0 \le i < j\)). Removing the vertex sequence between \(x_i\) and \(x_j\) to construct the path \(x_0, x_1, \dots, x_{i-1}, x_j, \dots, x_n\), we can obtain a shorter path. This contradicts the assumption that it is the shortest path.

Edge connectivity \(\lambda(G)\)

  • disconnected graph: \(\kappa(G) = \lambda (G)=0\)

For any graph \(G\),
\(\kappa (G) \le \lambda (G) \le \text{min}_{v \in V} \text{deg}(v)\)
In a simple graph, an edge is a bridge iff it does not belong to any cycle.

PROOF:

Let \(e = \{u, v\}\).

→:

  • Assume \(e\) is a bridge. If \(e\) were part of a cycle, then the remaining edges of the cycle would form a path from \(u\) to \(v\) after \(e\) was removed. Thus, removing \(e\) would not disconnect \(u\) and \(v\), contradicting that \(e\) is a bridge.

←:

  • Suppose that \(e\) lies on no cycle. If \(e\) were not a bridge, then there would still be a path from \(u\) to \(v\) in \(G - \{e\}\). Adding \(e\) to this path would form a cycle, a contradiction.

PROOF:

  1. Base case: \(r=1\), a path of length 1 means a single edge

  2. Inductive step
    Assume that for \(r\), the \((i,j)\) entry of \(A^r\) represents the number of paths of length \(r\) from \(v_i\) to \(v_j\). Consider \(A^{r+1}=A^r \cdot A\):

    \[ (A^{r+1}){ij} = \sum_{k=1}^n b_{ik}a_{kj}\]

    Here, \(b_{ik}\) is the \((i,k)\) entry of \(A^r\), and \(b_{ik}\) represents the number of paths of length \(r\) from \(v_i\) to \(v_k\)
    A path of length \(r+1\) is constructed by adding an edge from \(v_k\) to \(v_j\) to a path of length \(r\) from \(v_i\) to \(v_k\). Summing this number over all intermediate vertices \(v_k\) gives the total number of paths of length \(r+1\) from \(v_i\) to \(v_j\).

If a simple graph with \(n\) vertices has more than \((n-1)(n-2)/2\) edges, then it is connected.

PROOF: 反证法

Assume \(G\) is not connected, then it has multiple connected components.

  1. Partition
    Assume one connected component has \(k\) vertices (\(1 \le k \le n-1\)). Assume the remaining \(n-k\) vertices form another component.

  2. Maximum number
    The number of edges in a complete graph with \(k\) vertices is \(C_k^2\)
    The maximum total number of edges \(G\) can have is \(E_{\max}=\frac{k(k-1)}{2}+\frac{(n-k)(n-k-1)}{2}\)

  3. Quadratic function
    \(f(k)=\frac{k^2-k+(n-k)^2-(n-k)}{2}=\frac{2k^2-2nk+n^2-n}{2}\) 当 \(k=1\) or \(k=n-1\) 取得max
    \(f(1)=\frac{(n-1)(n-2)}{2}\)

A graph is bipartite iff it contains no odd cycle.

PROOF:

→:

  • Suppose that \(G\) contains no odd cycle.
  • Suppose that \(G\) is bipartite, with bipartition \(V(G) = A \cup B\).
  • Every edge has one endpoint in A and the other in B. Therefore, along any cycle, the vertices alternate between A and B. To return to the starting vertex, the cycle must have even length. Hence G contains no odd cycle.

←:

  • For a connected component \(C\), choose a vertex \(r \in V(C)\) and define \(A=\{v\in V(C):\text{ there is an even-length walk from }r \text{ to } v\}\) and \(B=\{v\in V(C):\text{ there is an odd-length walk from } r \text{ to } v\}\).
  • Since \(C\) is connected, every vertex belongs to \(A \cup B\).
  • No vertex belongs to both \(A\) and \(B\), otherwise there would be an odd cycle.
  • Let \(xy \in E(C)\). Appending \(xy\) to a walk from \(r\) to \(x\) changes its parity. Therefore, \(x\) and \(y\) belong to different sets.
  • Thus \((A, B)\) is a bipartition of \(C\). Applying this argument to every connected component shows that \(G\) is bipartite.

Euler & Hamilton

Euler Paths and Circuits: containing every edge

A connected multigraph with at least two vertices has an Euler circuit iff each of its vertices has even degree.

连通图 \(G\) 等价条件

  • \(G\) is Euler graph
  • \(\forall v \in V\), \(\deg(v)\) is even
  • \(E=C_{1} \cup C_{2} \cup \dots \cup C_{k}\), \(E(C_{i}) \cap E(C_{j})=\emptyset (i \neq j)\)

PROOF:

1→2

  • Let \(C\) be an Euler circuit in \(G\)
  • For any internal vertex in \(C\), the path must enter via one edge and exit via another, contributing 2 to its degree; The starting vertex contributes an out-degree of 1 at the beginning and an in-degree of 1 at the end. Any multiple passes through a vertex also contribute to its degree in pairs.

2→1

  1. Find a Cycle
    • Start a random walk from an arbitrary vertex  \(v_0\) along unvisited edges. For any internal vertex \(u \neq v_0\), since its degree is even, there must exist at least one untraversed edge to leave, meaning it cannot be a dead end. Since \(G\) has a finite number of edges, the walk must terminate at  \(v_0\), forming a cycle \(C_1\).
  2. Remove the Cycle
    • Remove all edges of \(C_1\) from \(G\)
    • Since every vertex on \(C_1\) loses exactly 2 edges, all vertices in the remaining graph \(G'\) still maintain an even degree
  3. Splice Cycles
    • If the remaining edge set is empty, the proof is complete.
    • If not:
      • Since \(G\) is connected, \(G'\) must share at least one vertex \(v_s\) with \(C_1\)
      • Starting from \(v_s\), repeat Step 1 within the connected component of \(G'\)to extract a new cycle \(C_2\)
      • Splice \(C_1\) and \(C_2\) at \(v_s\)
Hierholzer

\(O(E)\)

3→2

  • 假设 \(E\) 可以被划分为 \(k\) 个不共边的回路 \(C_1, …, C_k\)
  • 单个回路为它每个经过的顶点贡献了2个度数，不在回路中的顶点贡献为0
  • \(\deg(v) = \sum_{i=1}^k (\text{Degree contribution of } C_i \text{ to } v)\)
    • 每一项都是2或0，总和必然是偶数

2→3

  • 假设 \(G\) 所有顶点的度数均为偶数
  • 从任意一个度数非0的顶点  \(v_0\) 出发，沿着边走，每到一个新点，因为度数是偶数，总能找到一条未走过的边离开；最终必然回到一个已访问过的点形成回路 \(C_1\)
  • 从图 \(G\) 中移除 \(C_1\) 包含的所有边，得到 \(G'\)
    • 对于 \(G'\) 中的任意顶点 \(v\)
      • 若 \(v \in C_1\)，则 \(\deg_{G'}(v) = \deg(v) - 2\)
      • 若 \(v \notin C_1\)，则 \(\deg_{G'}(v) = \deg(v)\)
    • 原度数是偶数，减2或0，\(G'\) 中所有顶点度数仍是偶数
  • 如果 \(G'\) 中还有边，那么可以继续找一个回路 \(C_2\)，继续删除得到 \(G''\)；重复此过程
  • 图边数有限，有限步后边集为空，停止；\(E=C_{1} \cup \dots \cup C_{k}\)

A connected multigraph has an Euler path but not an Euler circuit iff it has exactly two vertices of odd degree.

PROOF:

→

  • Assume \(G\) has an Euler path \(P\), denoted by the vertex sequence \(v_0, …, v_m\)
  • For any internal vertex \(v\) (\(v \neq v_0\) and \(v \neq v_m\)), the path passes through, it pairs one entering edge with one leaving edge. Since \(P\) traverses every edge in \(G\) exactly once, \(\deg(v)\) must be even.
  • For \(v_0\), \(P\) begins with one leaving edge. Any other visits to \(v_0\) will contribute pairs of entering and leaving edges. So \(\deg(v_0)\) must be odd
  • For \(v_m\), \(P\) concludes with one entering edge. Any other visits to \(v_m\) will contribute pairs of entering and leaving edges. So \(\deg(v_m)\) must be odd
  • Euler path \(v_0 \neq v_m\)

←

  • According to Theorem 1, \(G\) has no Euler circuit

  • Let the two odd-degree vertices be \(u\) and \(v\), we add an edge \(e^*\) to connect them.
    Then both \(\deg(u)\) and \(\deg(v)\) increase 1, becoming even. Other vertices remain unchanged.

  • The new graph \(G'\) is connected and all vertices possess even degrees, applying Theorem 1, \(G'\) has an Euler circuit \(C\)

  • \(C\) must traverse \(e^*\)exactly once. By removing \(e^*\), the remaining trail traverses all edges of \(G\) exactly once, forming an Euler path beginning at \(u\) and terminating at \(v\).

A directed multigraph having no isolated vertices has an Euler circuit iff the graph is weakly connected and \(\text{deg}^-(v) = \text{deg}^+(v)\) for each vertex \(v\).

Hamilton Paths and Circuits: passing through every vertex exactly once

PROOF:

  • Assume that \(G\) satisfies Dirac’s condition
  • 任取 \(G\) 中一对不相邻顶点 \(u, v\)，则 \(\deg(u) \ge n/2\) 且 \(\deg(v) \ge n/2\)，于是 \(\deg(u) + \deg(v) \ge n\)，满足 Ore’s Theorem

PROOF:

  1. 反证法：Assume that \(G\) satisfies Ore’s condition but has no Hamilton circuit.
    • Add edges to \(G\) as long as the resulting graph still has no Hamilton circuit
    • The we obtain a maximal non-Hamiltonian graph \(G^*\) and adding any missing edge to it will create a Hamilton circuit
    • Since adding edges only increases vertex degrees, \(G^*\)still satisfies Ore’s condition
  2. Choose two nonadjacent vertices \(u\), \(v\) in \(G^*\). Adding the edge \((u,v)\) creates a Hamilton circuit. Removing this edge from the circuit gives a Hamilton Path \(P=v_1,...,v_n\) (\(v_1=u\), \(v_n=v\)) in \(G^*\).
  3. Define:
    • \(A = \{ i|(u,v_{i+1}) \in E(G^*) \}\)
    • \(B = \{ i|(v,v_{i}) \in E(G^*) \}\)
    • \(|A| = \deg (u)\), \(|B| = \deg (v)\), by Ore’s condition, \(|A| + |B| \ge n\)
    • Both \(A\) and \(B\) are subsets of \(\{1, … ,n-1\}\) which has \(n-1\) elements. By the Pigeonhole Principle, \(A \cap B \neq \varnothing\)
  4. \(\exists k \in A \cap B\), \((v_1, v_{k+1}) \in E(G^*)\) and \((v_n, v_k)\in E(G^*)\)
    • We can form a Hamilton circuit: \(v_1,v_2,\dots,v_k,v_n,\dots,v_{k+1},v_1\)
    • This contradicts the assumption that \(G^*\) has no Hamilton circuit

Planar & Coloring

Planar: without any edges crossing

The degree of a region: the number of edges included in the boundary of that region

Chromatic number: \(\chi(G)\)

PROOF:

  1. Construct Planar representation: \(G_1, G_2, \dots, G_e = G\)
    Select any one edge to create \(G_1\). Create \(G_n\) by adding a new edge to the existing subgraph \(G_{n-1}\). At this time, the new edge must be connected to a vertex that already exists in \(G_{n-1}\)

  2. Base case: \(G_1\) has 1 edge and 2 vertices, and the number of regions is 1.

  3. Inductive step
    Assume that \(r_k = e_k - v_k + 2\) holds for \(G_k\). Let \(G_{k+1}\) be the graph obtained by adding \(\{a_{k+1}, b_{k+1}\}\) to \(G_k\).

    • Case 1: Both \(a_{k+1}\) and \(b_{k+1}\) already exist in \(G_k\)
      • The new edge divides an existing region into two, so \(r_{k+1} = r_k + 1\)
      • \(e_{k+1} = e_k + 1\)
      • \(v_{k+1} = v_k\)
    • Case 2: Either \(a_{k+1}\) or \(b_{k+1}\) does not exist in \(G_k\)
      • \(r_{k+1} = r_k\)
      • \(e_{k+1} = e_k + 1\)
      • \(v_{k+1} = v_k+1\)

  4. \(r_n = e_n - v_n + 2\) holds for all \(G_n\)

If G is a connected planar simple graph with e edges and v vertices, where v ≥ 3, then \(e \le 3v -6\)

PROOF:

  • A connected planar simple graph drawn on a plane divides the plane into \(r\) regions. The degree of each region ≥ 3

    • Simple: regions of degree 2 or 1 are never formed
    • \(v\) ≥ 3: the infinite region also has a degree of at least 3

  • Since every edge of the graph appears twice on the boundaries of the regions, and the degree of each region is at least 3, we have:

    \[ 2e = \sum_{\text{faces } R} \deg(R) \ge 3r\]

    Therefore, \(2e \ge 3r\)

  • Euler’s Formula
    \(2e \ge 3(e - v + 2)\)
    \(e \le 3v - 6\)

If G is a connected planar simple graph, then G has a vertex of degree ≤ 5

PROOF:

  • If \(|E|=\) 1 or 2, the degree of all vertices ≤5
  • \(|E|\ge 3\):
    • Handshaking Theorem
    • Assume the degree of all vertices ≥ 6: \(\sum_{v \in V} \deg(v) = 2e \ge 6v\)
    • There is a contradiction with \(e \le 3v - 6\)

If a connected planar simple graph has e edges and v vertices with v ≥ 3 and no circuits of length 3, then \(e \le 2v - 4\)

PROOF:

If a connected planar simple graph has e edges and v vertices, and no simple circuits of length 4 or less. When v≥ 4, \(e\le\frac{5}{3}v-\frac{10}{3}\)

Trees

PROOF:

→

  • Consider two vertices \(x\) and \(y\) in \(T\). Since \(T\) is connected, there exists a simple path between \(x\) and \(y\).
  • If a second path exists, a circuit is formed by advancing from \(x\) to \(y\) along this path, and returning from \(y\) to \(x\) in reverse order along the second path. However, since a tree has no simple circuits, a contradiction arises. Therefore, the simple path between any two vertices is unique.

←

  • \(T\) is connected because a path exists between any two vertices.
  • Suppose a simple circuit exits, then there would be two different simple paths connecting two vertices \(x\) and \(y\) on that circuit, the path would not be unique. Therefore, \(T\) has no simple circuits.

A tree with \(n\) vertices has \(n-1\) edges.

PROOF:

  1. Base case: A tree with 1 vertex has no edges.

  2. Inductive step
    Assume that a tree with \(k\) vertices has \(k-1\) edges.

    • Let \(T\) be a tree with \(k+1\) vertices, and assume \(v\) is a leaf of \(T\) (a leaf exists because the tree is finite). Let \(w\) be the unique vertex adjacent to \(v\).
    • By removing \(v\) and \((v,w)\) from \(T\), we obtain a subgraph \(T'\) with \(k\) vertices. \(T'\) remains connected and does not contain any simple circuits.
    • \(T'\) has \(k-1\) edges. Since \(T\) is formed by adding exactly one edge \((v,w)\) to \(T'\), the total number of edges in \(T\) is \(k\).

A full m-ary tree with \(i\) internal vertices contains \(n = mi +1\) vertices.

A rooted m-ary tree of height \(h\) is balanced if all leaves are at levels \(h\) or \(h - 1\).

There are at most \(m^h\) leaves in an m-ary tree of height \(h\).

PROOF:

  1. Base case: \(h=1\)

    • This tree has a root and at most \(m\) children, all of which are leaves. Therefore, the number of leaves is at most \(m^1 = m\).

  2. Inductive step
    Assume that this result holds for any m-ary tree of height less than \(h\).

    • Let \(T\) be an m-ary tree of height \(h\). The leaves of \(T\) are the leaves of the subtrees. The height of these subtrees is at most \(h-1\). Therefore, the number of leaves in each subtree is at most \(m^{h-1}\).
    • Since the number of these subtrees is at most \(m\), the total number of leaves is at most \(m^h\).




Every tree is bipartite.

PROOF:

  • Choose an arbitrary vertex \(r\) as the root
  • Define: \(V_0=\{v\in V:d(v) \text{ is even}\}\) and \(V_1=\{v\in V:d(v) \text{ is odd}\}\)
  • For every edge \(\{ u, v\}\), we have \(|d(u)-d(v)| = 1\) and \(u\) and \(v\) belong to different sets. Therefore, \((V_0, V_1)\) is a bipartition of the tree.

A simple graph is connected iff it has a spanning tree.

PROOF:

←

  • A simple graph \(G\) has a spanning tree \(T\).
  • \(T\) contains all the vertices of \(G\), and paths exist between its vertices. Since \(T\) is a subgraph of \(G\), a path also exists between any two vertices in \(G\). Therefore, \(G\) is connected.

→

  • If connected \(G\) is not a tree, it contains a simple circuit. Remove one edge from that circuit. At this time, the resulting subgraph has one less edge, yet it contains all the vertices of \(G\) and is connected. (because any two vertices in the cycle that contained the removed edge are still connected by a path that does not include the removed edge)
  • By repeating this operation, all simple circuits in \(G\) are removed. Since the number of edges in the graph is finite, this process terminates in a finite number of steps. As a result, a connected graph with no circuits remains. Since this graph is a tree and contains all the vertices of \(G\), it is a spanning tree.

Let \(T_1, T_2\) be spanning trees of a simple graph \(G\).
For any edge \(e_1 \in T_1 \setminus T_2\), there exists an edge \(e_2 \in T_2 \setminus T_1\) such that:

  1. \(T_1' = (T_1 \setminus \{e_1\}) \cup \{e_2\}\) is a spanning tree
  2. \(T_2' = (T_2 \setminus \{e_2\}) \cup \{e_1\}\) is a spanning tree

PROOF:

  • Removing \(e_1 = (u,v)\) from \(T_1\) divides the tree \(T_1 - \{e_1\}\) into exactly two connected components \(A\) and \(B\), with \(u\in A\), \(v \in B\).
  • Adding \(e_1\) to \(T_2\) creates a simple cycle \(C\) within \(T_2 \cup \{e_1\}\). Since \(C\) contains \(e_1\), the remaining path \(C- \{e_1\}\) connects \(u\) and \(v\), so it must contain an edge \(e_2\) crossing the cut \((A,B)\).
  • Since \(e_2\) lies on \(C\), removing \(e_2\) breaks the cycle. The resulting graph \(T_2 \cup \{e_1\} - \{e_2\}\) remains connected and forms a tree that contains all the vertices of \(G\).
  • \(e_2\) precisely connects two disjoint components in \(T_1 - \{e_1\}\). Therefore, \((T_1 - \{e_1\}) \cup \{e_2\}\) becomes connected again and forms a tree containing all vertices.

Construct MST

  • Prim

    • PROOF:
      At each step, Prim chooses the minimum-weight edge crossing the cut between \(B\) and \(V-B\). Let \(e\) be this edge. Consider an MST \(T\) containing all edges chosen so far.
      If \(e\notin T\), adding \(e\) to \(T\) creates a cycle, which contains another edge \(f\) crossing the same cut. Since \(e\) is the minimum edge crossing the cut, \(w(e) <= w(f)\). Replacing \(f\) by \(e\) gives another spanning tree whose weight ≤ \(T\). Hence it is also an MST and contains \(e\).
      Therefore, each edge chosen by Prim is safe. After \(|V|-1\) steps, the chosen edges form a spanning tree, which is a MST.
